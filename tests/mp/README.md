# Materials Project reference data

`thermo_Cl-Li-P-S_GGA_GGA+U_R2SCAN.json` contains the 108 thermo documents of the Cl-Li-P-S system
and all its sub-systems (thermo type `GGA_GGA+U_R2SCAN`, database version 2026-09-28), in the same
shape as a `/materials/thermo/` API response. It was extracted from the Materials Project
collection on AWS Open Data (`s3://materialsproject-build/collections/thermo/`).

Data: Materials Project, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
A. Jain et al., "Commentary: The Materials Project", _APL Mater._ **1**, 011002 (2013).

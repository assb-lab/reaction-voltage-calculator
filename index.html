Reaction Voltage Calculator

Materials Project の計算エネルギーから、指定組成を作動イオンの開放系に置いたときの相平衡と反応電位 (電気化学的安定性ウィンドウ) を計算します。計算はすべてブラウザ内で行われます。

はじめに

  1. Materials Project の API key を用意

    materialsproject.org にログインし、アカウントメニューの API key をコピーします。key は MP API への問い合わせにだけ使われます。

  2. 組成を入れて計算

    組成 (例: Li6PS5Cl) と作動イオンを選び、「MP から取得して計算」を押します。取得済みの元素の範囲なら、組成を変えるだけで再計算されます。

  3. 図を読む

    横軸 x は対象 1 式量あたりのイオン取込量 (x < 0 が酸化、x > 0 が還元)。灰色の帯が対象相の安定性ウィンドウ、右側は各電位で安定な相の組み合わせです。

デモデータは架空のエネルギーです。「使い方」からいつでも再表示できます。

データ

コマンドで取得 (公開サイトではこちら)

Materials Project API はブラウザからの直接通信 (CORS) を materialsproject.org にしか許可していないため、公開サイトからは「MP から取得」できません。端末で次のコマンドを実行し、保存された JSON を「JSON を読み込む」で選んでください (複数ファイルをまとめて選択できます)。

  1. API key を環境変数に設定
  2. データを取得 (組成・作動イオン・thermo type に合わせて自動で更新されます)
  3. 保存された を「JSON を読み込む」で選択

1 ファイルは最大 1000 件です。件数が足りない場合は読み込み時に警告が出るので、URL の _page=1 を 2, 3… に変えて取得し、すべてのファイルを一緒に選んでください。 vp dev / vp preview でローカル起動した場合は、開発サーバのプロキシ経由で「MP から取得」がそのまま使えます。

オプション

準安定な対象相もプロットに含めて評価します。元のエネルギーでの平衡相を調べる場合は チェックを外してください。該当エントリがない組成の仮想相は作りません。

  • 酸化側 (x < 0, イオン脱離)
  • 還元側 (x > 0, イオン挿入)
  • 安定性ウィンドウ
  • x: 対象 1 式量あたりの作動イオン取込量 / 水平線: 二相共存の電位

相平衡と反応

電位は V = −(μ − μmetal)/z。Ong et al., Chem. Mater. 20, 1798 (2008); Zhu, He & Mo, ACS Appl. Mater. Interfaces 7, 23685 (2015) の手法に基づく grand potential 相図による評価です。
